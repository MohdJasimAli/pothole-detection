# Sample Images Directory

Place sample road images here for testing the detection pipeline.

## Expected Format
- JPEG or PNG images of road surfaces
- Images should contain visible potholes for detection
- Recommended resolution: 1280x720 or higher

## Example Usage

```bash
python main.py --image data/samples/road1.jpg
```
